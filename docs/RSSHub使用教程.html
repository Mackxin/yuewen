阅闻 · v2.1 新功能

用 RSSHub 订阅微博、知乎、B站这些「没有 RSS」的网站

从零到订上一个微博账号，大约两分钟。看完这份就不会卡在「ID 去哪找」上了。

先说结论（30 秒版）
打开 阅源 页 → 点右上角那个 网络图标 → 挑一条模板 → 把 ID 填进去 → 看到预览没问题 → 点订阅。
找不到的站点，用页面里的「自定义路由」自己填一条路径 —— 这样 RSSHub 上千条路由你都能用。

一、RSSHub 是个什么东西

一句话：它是个「转接服务」，专门把没有 RSS 的网站，转成有 RSS 的。

微博、知乎、B站、小红书、抖音这些平台都是自己的 App 里看，不对外提供订阅地址。RSSHub 就干一件事：替你去把这些内容抓下来，按标准格式吐出来一个订阅地址。然后你把那个地址丢进任何阅读器，就能像订博客一样订它们。

所以它和阅闻不是竞争关系，而是上下游：

① 内容源
微博某个账号
知乎热榜
B站某个 UP 主
→
② RSSHub（转接）
把这些内容转成
一个标准 RSS 地址
→
③ 阅闻（阅读）
订阅、分类、收藏
笔记、朗读、离线

关键点：阅闻只负责「把地址拼对」，剩下全是它本来就有的能力。订进来的微博和订进来的少数派，在同一张列表里排着，收藏夹、朗读、离线缓存全都能用 —— 这些恰恰是 RSSHub 给不了的。

二、地址是怎么拼出来的（看懂这一条就懂全部）

实例地址 + 路由 = 订阅地址

https://rsshub.app  +  /weibo/user/1642909335
= https://rsshub.app/weibo/user/1642909335
  • 实例：一台跑着 RSSHub 的服务器。默认用官方公共的 rsshub.app，也可以换成你自己搭的。
  • 路由：/weibo/user/1642909335 这样一段路径，决定「要哪个站点的哪份内容」。

App 里你不需要手拼这个地址 —— 挑模板、填 ID，它替你拼。但下面会把这个地址显示出来，方便你复制去别处用。

三、三步订上一个微博账号

从「阅源」页进 RSSHub
底部点 阅源 → 右上角那个 网络图标。或者在「我的阅源」列表上方那条 RSSHub 提示上点「去添加」。
挑模板，填 ID
页面按平台分好了组（微博 / 知乎 / B站 / 抖音 / 小红书 / 豆瓣 / 资讯 / 开发 / 社交）。点「某个用户的微博」，把你要追的 UID 填进去。每条下面都写了这个 ID 去哪复制。
看清预览，再点订阅
填完 ID 会自动测一遍，把 源名、格式、文章数、最新几条标题 摆出来。是你要的内容就点「订阅」；如果显示失败，换一个源或者等一会儿再试（多半是公共实例限流了）。
订阅之后在哪看？
会归到以平台命名的分类里（比如「微博」）。回首页往下拉一下刷新，就在列表里了。想改名或换分类：阅源 → 我的阅源，点那一行就能改。

四、那些 ID 到底去哪找

这一步 90% 的人会卡住。按下面这张表抄就行 —— App 里每条模板下面写的也是同样的内容。

微博
用户 UID（一串数字）
打开 ta 的微博主页 → 地址栏 weibo.com/u/ 后面那串数字，例如 1642909335
关键词
直接填词就行，中英文都行
知乎
用户 ID（不是昵称）
主页地址 zhihu.com/people/ 后面那一段，例如 excited-vczh
专栏 ID
专栏地址 zhuanlan.zhihu.com/ 后面那一段，形如 c_1129398137630167040
B站
UP 主 UID（一串数字）
UP 主主页地址 space.bilibili.com/ 后面那串数字，例如 2267573
抖音
sec_uid（很长一串）
抖音上点 ta 主页右上角「分享」→ 复制链接，链接里 sec_uid= 后面那 60 多位
话题
话题名，带不带 # 都行
小红书
用户 ID（24 位）
主页分享链接里 user/profile/ 后面那 24 位字母数字
豆瓣
用户 ID
主页地址 douban.com/people/ 后面那一段，例如 ahbei
GitHub
仓库
填「作者/仓库名」，斜杠分开，例如 DIYgod/RSSHub
某语言的趋势
英文小写语言名，例如 kotlin、python
少数派 / 掘金
作者 ID
少数派：sspai.com/author/ 后面那段
掘金：juejin.cn/user/ 后面那串数字
小技巧：在手机浏览器里打开目标主页，地址栏里那一段能直接长按复制，比在 App 里翻设置快得多。

六、找不到的站点：用「自定义路由」

模板只有二十几条，RSSHub 实际有 上千条。找不到的时候不用等我加 —— 自己填一条就行，功能完全一样。

去官网查路由
在 RSSHub 的「路由大全」里搜站点名（页面左上角有搜索框）。每条路由下面都会给一个示例地址。
照抄「斜杠后面」的部分
示例给的是 https://rsshub.app/xxx/yyy/123，你要填的是 xxx/yyy/123 —— 也就是去掉域名那一截。
粘进「自定义路由」
在 RSSHub 页面上点那条蓝色的「自定义路由」卡片，把路径填进去。它会自动测一遍再让你订阅。
懒人模式：整条地址直接粘进来也能用。App 会自动把 https://rsshub.app 这一截去掉，只留路由。路由末尾的 ?limit=20 这类参数也会保留。

七、要不要换「实例」

默认用的是官方公共实例 rsshub.app。它是完全免费的公共服务，所以有两个现实：

  • 有限流。大概每小时 200 次请求 / IP，订得多 + 刷新得勤，就会开始取不到东西。
  • 不一定随时可用。官方文档自己都写了，它不适合长期重度依赖。

所以这一页顶部那一条可以点「切换」：填一个你自己的实例地址，之后所有订阅都走它。自己搭一个不难 —— 有服务器的话用 Docker 一行命令，没有的话用 Vercel 一键部署（RSSHub 官网有部署文档）。搭建完之后把地址填进来就行，其他什么都不用改。

什么时候该考虑自建？ 如果你订了十几个源、每天都会刷新，或者发现「明明之前能用的路由突然全部失败」—— 那基本就是限流了，自建能一次性解决。

八、常见问题

测出来失败 / 一直是「取不到」，怎么办？
按概率从高到低排查：
① 公共实例限流了 —— 最常见。等十几分钟再试，或者换个时间。
② 平台反爬 —— 微博、知乎、抖音、小红书本身就不欢迎抓取，偶尔成功偶尔失败是常态。
③ 这条路由失效了 —— 平台改版，RSSHub 的路由要跟着更新。去官网看看还有没有能用的替代路由。
④ ID 填错了 —— 尤其知乎（要 people 后面那段，不是昵称）和小红书（要 24 位）。
为什么订进来的微博没有图片 / 只有文字？
两种常见原因：源站图片做了防盗链（App 已经尽量兼容，个别图挂了不影响读正文），或者该平台对抓取做了限制，只给了部分字段。这不是阅闻的问题 —— 换任何阅读器都一样。
同一个账号我订了两次，会重复吗？
不会。拼出来的地址一样时，App 会直接告诉你「这个地址已经在你的阅源里了」，按钮也会变成不可点。列表里同样按地址去重。
这些内容会存在哪？会上传吗？
和其他阅源完全一样：抓回来的文章存在你手机本地的数据库里，不上传任何服务器。清除缓存只会删掉未收藏的文章与已缓存正文。唯一的外部请求是「向 RSSHub 实例要 RSS」这一步。
我把实例地址改回官方默认，怎么操作？
实例那一行点「切换」，对话框里有一条「恢复默认（官方公共实例）」，点一下就回去了。App 里存的是「空 = 用默认」，所以以后官方换了默认实例，你会自动跟着走。
